# Excel Semantic Merge Releases

This public repository contains signed Windows releases for **Excel Semantic Merge**.

- [Download the latest release](https://github.com/MiaoSir-YH/SVNExcelMerge-Releases/releases/latest)
- The application verifies every in-app update with its embedded Tauri updater public key.
- Source code is maintained in a private repository; no workbook data is uploaded here.

Release assets include the Windows x64 NSIS installer, its detached signature, and `latest.json` for the in-app updater.
